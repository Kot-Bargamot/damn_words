# Comparative and Superlative adjectives

## Объяснение

- Formation of comparative and superlative adjectives depends on adjective length. [1]

## Условия употребления

- One‑syllable adjectives add -er / -est (or -ier / -iest); longer adjectives use more / most. [1]

## Конструкции

- small → smaller → smallest; interesting → more interesting → the most interesting; bad → worse → the worst; good → better → the best; little → less → the least; much/many → … → the most; far → farther/farthest (distance) or furthest (extra, more). [1]

## Примеры из материалов

- small → smallier → smallest (один слог, + мб y окончание); interesting → more interesting → the most interesting (longer adj); bad → worse → the worst; good → better → the best; little → less → the least; far → the farthest (about distance)/the furthest (=extra, more). [1]
