# Used to

## Объяснение

- Used to употребляется для прошлых привычек и состояний, которые больше не истинны или не происходят регулярно, а также для подчёркивания различий между прошлым и настоящим. [1]

## Условия употребления

- Для описания привычек/состояний в прошлом, которые сейчас изменились; для акцентирования различий между прошлым и настоящим. [1]

## Конструкции

- Утвердительная форма: S + used to + V1; Отрицательная форма: S + did not (didn’t) + use to + V1; Вопросительная форма: Did + S + use to + V1. [1]

## Примеры из материалов

- He used to read a lot, but now he doesn’t read books. She used to read a lot in childhood. We didn’t use to go camping every summer. I never used to get up so early before. Where did you use to work before you came here? [1]
